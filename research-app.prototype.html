Interactive concept · fictional sessions · changes stay in memory only
The application, kept simple
Choose project→New session→Choose questionnaire→Notes + audio→Export
01

A list of sessions

Open an existing session or start a new one. Tick one, several, or all sessions to export. Search by title, person, questionnaire, or written answers.

02

Your questionnaire, ready for the conversation

Keep named questionnaire groups in each project: First impressions, Usability test, Follow-up, or your own. Choose a group or a blank form when starting a session. Fill in the person, date, and answers while recording. Add notes or extra questions as needed.

Each session gets its own copy of the questions. Editing a reusable questionnaire affects future sessions; it never rewrites previous answers.

03

One export dialog

Export only the sessions you chose. Markdown gives Codex or Claude Code your written questions, answers, and notes. JSON preserves the structure. ZIP bundles both formats with original recordings. One session, a few, or the whole project use the same flow.

Desktop build: Tauri interface, Rust for recording and files, SQLite for local data, and original audio stored beside it. No account. No server. Build the form and selection/export first, then reliable microphone recording, import, and playback. Transcription and live agent integrations are outside this version.
